# Site Fogaca - Landing Page

## Stack
- HTML/CSS/JS puro
- Google Fonts (Playfair Display, DM Sans)
- Deploy: Vercel

## Agentes
- **Design Agent**: Responsável por criar/atualizar a landing page
- **SEO Agent**: Otimização para mecanismos de busca

## Convenções
- Arquivo único: index.html
- CSS embutido no <style>
- JS embutido no <script>
- Sem dependências externas além do Google Fonts
- Design responsivo mobile-first
